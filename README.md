# India UG Scholarships App (Nov 2026)

Interactive single-file HTML web app listing recent undergraduate scholarships in India.

## Features
- Searchable & sortable scholarship cards
- Deadline highlighting
- Details: name, amount, application date, eligibility

## Data Sources
Compiled from announcements and portals around 15–22 November 2026 (INSPIRE, Ashoka University, Rolls-Royce, Colgate, ONGC, Vylor, Nirankari, FFE, UGC Ishan Uday, PM-USP CSSS, etc.).

**Always verify on official websites** (scholarships.gov.in, Buddy4Study, university sites) as deadlines and criteria can change.

## Hosting on GitHub Pages
1. Go to repository **Settings** → **Pages**
2. Under **Build and deployment**, select **Deploy from a branch**
3. Branch: `main`, Folder: `/ (root)`
4. Save. The site will be live at: `https://not56971-art.github.io/india-ug-scholarships-app/`

The `index.html` is already in the root.
